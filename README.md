# Hatcher Ltd — Homebrew tap

Casks for software from [hatcher.ltd](https://hatcher.ltd).

```sh
brew install --cask hatcher-ltd/tap/transcripts
```

## Transcripts

Voice notes and meeting transcripts, recorded and transcribed on your own
device. Records both sides of a call on the Mac, tells the speakers apart, and
files the result into a folder you choose — nothing is uploaded.

[transcripts.hatcher.ltd](https://transcripts.hatcher.ltd) ·
[User guide](https://transcripts.hatcher.ltd/guide/)

---

This tap contains packaging only. The applications themselves are proprietary;
the cask points at signed, notarized builds published at hatcher.ltd.
